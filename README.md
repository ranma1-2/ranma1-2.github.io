# Ranma ½ Index

An independent collection of Ranma ½ content and resources, including a support
guide, a manga–anime comparison and an archive of Anime Trending poll results.

English is the base language, and the site can be extended to support additional
languages. Italian is already available, and contributions in other languages are
welcome. See [CONTRIBUTING.md](CONTRIBUTING.md) to request or add a language.

The site is built as static HTML from Markdown content and structured JSON data,
and deployed through GitHub Pages.
